# Legacy Dash
This mod brings back old Geometry Dash, like 2.1, 2.0 or even 1.9. Maybe even older later.

This is a recreation, it is impossible to restore old GD back with the flick of a switch lmao.

## Features
- Remove discord & twitch from social media
- Pre-2.2 socials style (positions)
- Pre-2.2 twitter icon
- Pre-2.2 newgrounds button
- Remove newgrounds button
- Remove daily chest
- Pre-2.0 more games button size
- Remove profile button
- Pre-2.2 & 2.0 search
- Pre-2.2 & 2.0 quick search
- Pre-2.2 top right menu positioning in level search menu
- Remove lists from level search menu
- Pre-2.2 clock & star positioning in level search menu
- Remove platformer or platformer & xl length filter
- Pre-2.2 free stuff button sprite in daily rewards popup
- Pre-2.2 free socials popup
- Remove menu music toggle from settings
- Pre-2.2 back button position in settings
- 2.2, 2.1 and 2.0 icon kit & creator layer style (individual settings)
- Pre-2.2 settings in pause
- Remove reset button in pause
- Pre-2.2 button spacing in pause
- Remove cocos2d & fmod logo in loading screen

Each of these are a setting. None are forced and half aren't enabled by default. With configuring you can make the game look like 2.1, 2.0 or 1.9 through these.

Note this mod is not done.
